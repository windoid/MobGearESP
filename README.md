# Mobgear Addon

A Meteor Client addon that detects mobs carrying or wearing player equipment.

Originally written by me, included in Trouser Streak, and improved by etianl. Trying to keep 
this repo up to date with Trouser Streak's version because there's no 1.21.1 release of Trouser Streak.
The item ESP module was entirely written by etianl, based on the original MobGearESP cade.

### How to use

Download the latest release and stick it in your mods folder! Have Meteor Client installed. 

### Building

I encourage you to build the project yourself: `./gradlew build`
